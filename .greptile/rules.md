## Public landing page — scope check

Single-page marketing site, no auth, no customer data. Flag any change that:
- Introduces a Supabase call using anything other than the public/anon key, or otherwise embeds a service-role/secret credential client-side.
- Hand-edits `src/routeTree.gen.ts` — generated by `bun run generate-routes`, never edit directly.
- Adds heavy synchronous work to the 3D hero (`react-three-fiber`/`three`, `fx/`, `backdrop/`) that would block or meaningfully delay initial page render — this is a first-impression landing page, perf regressions here matter more than on an internal tool.

## Style

- Bun + Biome — don't suggest npm/yarn/ESLint/Prettier.
- New page sections are components under `src/components/` composed into the single `index.tsx` route, not new routes (this site currently has no multi-page navigation beyond the root).
